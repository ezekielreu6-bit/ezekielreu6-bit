## 🚀 What I'm building

### [Profyl](https://getprofyl.cv)
A block-based professional identity platform that grew out of a link-in-bio tool.
- Three identity types: **Creator**, **Professional**, **Portfolio**
- Flexible blocks: About, Links, Projects, Skills, Experience, Currently, Companies, Testimonials, Services, Contact/Inbox
- Six templates: Folio, Bento, Studio, Signal, Market, Archive
- Custom domains, Pro billing, analytics, and an **MCP server** that lets AI assistants manage a profile
- Myhappr OAuth sign-in, uploads on Cloudflare R2, and a built-in blog

### [FORX](https://forx.voryn.xyz)
Form submission infrastructure. Point any form at an endpoint and FORX handles delivery.
- Endpoints, submissions, webhooks and email notifications to form owners
- Cloudflare Turnstile bot protection, session management, and idempotent multi-recipient delivery

### [vendX](https://vendx.voryn.xyz)
A creator storefront app with dashboard settings, avatar and product image uploads, and public storefront pages.

### [FireMigrate](https://firemigrate.voryn.xyz/)
An open-source CLI that migrates **Firebase (Firestore + Auth) to Postgres**. Dry-run by default, honest inspection of real data, with `migrate --write` and `verify` steps.

```bash
npx @ezekielreu6/firemigrate --help
```

📦 [npm](https://www.npmjs.com/package/@ezekielreu6/firemigrate) · 🔗 [GitHub](https://github.com/ezekielreu6-bit/firemigrate)
